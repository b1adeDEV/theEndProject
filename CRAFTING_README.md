# B1ADE DEV — система крафта

## Запуск (Windows)
1. Установите Node.js и Python 3.10+.
2. В корне проекта: `npm install`.
3. В корне проекта: `python -m pip install -r backend/requirements.txt`.
4. Запустите `npm run dev:all` (либо отдельно `npm run dev:backend` и `npm run dev:frontend`).
5. Откройте http://127.0.0.1:5173/crafting.

## API
- `GET /api/crafting/recipes` — пять рецептов.
- `POST /api/crafting/craft` — JSON `{"recipeId":"campfire_kit","amount":1}`.
- Ответ содержит актуальное состояние инвентаря; при недостатке ресурсов или места возвращается HTTP 409.
- Инвентарь хранится в `backend/data/inventory.json` (как и в исходном проекте).

## Важно
- Система крафта работает с общим инвентарём, как и исходный проект. Для многопользовательского режима нужно перевести состояние на индивидуальные аккаунты и защитить все операции с инвентарём авторизацией.
- Размеры созданных предметов пока отображаются в одной ячейке: это ограничение исходного интерфейса инвентаря.
- Если предметы израсходованы, добавьте исходные ресурсы на вкладке ADD ITEMS.
